# Human-in-Purpose Protocol draft v0.1

## Core idea

Before a significant AI action on behalf of a human, the system should make visible:

1. goal;
2. boundaries;
3. concrete authorized action;
4. right to stop;
5. result status;
6. possible divergence from the human's own intent.

## Minimal loop

```text
Intent Contract
  → AI Action Proposal
  → Protected Confirmation
  → Stop / Execute / Cancel
  → Result Status
  → Echo / Research Questionnaire
