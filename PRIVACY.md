# Privacy Notes

## Current public repository

This repository does not collect personal participant data.

Please do not post in public Issues:

- real names;
- emails;
- phone numbers;
- client data;
- medical details;
- psychological states;
- confidential company materials;
- real messages;
- personal identifiers.

## Public Issues are not for participant data

GitHub Issues in this repository are for professional critique and non-personal discussion only.

Future participant responses will be collected only through a separate, access-controlled channel after informed consent and data minimization procedures are prepared.

## Future participant data

Participant data will only be collected after:

1. informed consent is prepared;
2. a private collection channel is defined;
3. data minimization is approved;
4. storage and deletion rules are set;
5. anonymization policy is defined;
6. the pilot harness is tested.

## Minimal data principle

For the exploratory pilot we aim to collect only:

- pseudonym / alias;
- condition: A / B / C / optional B+;
- task type;
- system events;
- short comprehension answers;
- detected mismatch result;
- voluntary echo;
- consent for anonymous use.

## Not collected by default

- real names;
- biometrics;
- geolocation;
- medical data;
- psychological diagnoses;
- trauma details;
- children's data;
- confidential corporate data.

## Intent text sensitivity

The pilot may involve user-stated goals, boundaries, and enoughness criteria.

Even short intent statements can be sensitive. They may reveal:

- workplace conflict;
- personal relationship tension;
- health-related communication;
- financial stress;
- family situation;
- private decision context.

Therefore:

1. Synthetic tasks are preferred for Pilot 01.
2. If free-text intent is allowed, it must be clearly optional.
3. Free-text intent should be stored locally by default.
4. Analysis should prefer redacted or hashed representations where possible.
5. Verbatim intent text must not be published without explicit consent.
6. Participants must be warned not to enter confidential company data, real client data, medical details, or private messages.
7. Participants may delete their intent text and associated records on request.
8. If a participant enters potentially sensitive real-world content, the maintainer should remove or anonymize it before any shared analysis.

Русский:

В пилоте могут участвовать формулировки цели, границ и критерия достаточности, написанные пользователем.

Даже короткие intent-тексты могут быть чувствительными. Они могут раскрывать:

- конфликт на работе;
- напряжение в личных отношениях;
- медицинский контекст;
- финансовые трудности;
- семейную ситуацию;
- приватный контекст принятия решения.

Поэтому:

1. Для Pilot 01 предпочтительны синтетические задачи.
2. Если допускается free-text намерение, он должен быть явно добровольным.
3. Free-text намерение по умолчанию хранится локально.
4. Для анализа предпочтительны redacted или hashed представления, где это возможно.
5. Дословные intent-тексты не публикуются без явного согласия.
6. Участник должен быть предупреждён не вводить конфиденциальные корпоративные данные, реальные клиентские данные, медицинские подробности или личные сообщения.
7. Участник может удалить свой intent-текст и связанные записи по запросу.
8. Если участник вводит потенциально чувствительный реальный контент, мейнтейнер должен удалить или анонимизировать его перед любым совместным анализом.

## Rights

Future participants should be able to:

1. stop at any time;
2. skip questions;
3. withdraw consent;
4. request deletion;
5. refuse anonymous publication;
6. understand what data is collected.

## Vulnerable participants

The first pilot should avoid recruiting people in acute crisis or severe distress unless there is separate professional ethical supervision.

If a task causes strong discomfort, the procedure must allow immediate stopping without pressure.

Русский:

Первый пилот не должен набирать людей в остром кризисе или тяжёлом дистрессе без отдельного профессионального этического сопровождения.

Если задача вызывает сильный дискомфорт, процедура должна позволять немедленную остановку без давления.
